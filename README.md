# IT-OT Cybersecurity Home Lab

This repository documents my hands-on IT/OT cybersecurity home lab as I build practical skills in networking, system administration, SOC operations, and industrial cybersecurity.

## Lab Environment

### IT Infrastructure
- Cisco Catalyst 3750X Switch
- Cisco 1900 Series Router
- Windows 11 Laptop
- Windows Server 2022
- Hyper-V

### OT / ICS
- PLC
- HMI
- Modbus TCP
- MQTT
- Industrial network monitoring

## Lab 01 - Cisco Network Infrastructure

### Objective
Build and secure the basic network infrastructure for my IT/OT home lab.

### Work Completed
- Connected to Cisco switch and router through console
- Configured VLANs
- Created a dedicated management VLAN
- Configured switch access ports
- Configured an 802.1Q trunk between the switch and router
- Configured Router-on-a-Stick
- Configured SSH remote management
- Tested remote SSH access to the switch and router
- Saved device configurations

### Skills Practiced
- Cisco IOS
- VLANs
- 802.1Q trunking
- Router-on-a-Stick
- SSH
- Network troubleshooting
- Secure device management
